# Release checks

## Included and verified locally
- Historical aggregate tables retained; deterministic outputs and automated tests included.
- Management clarification records are separated from historical arithmetic and later dashboard context.
- No unverified field-to-venture conversion or physical CPU/GPU utilization metric is generated.
- Original private source archive and reviewer correspondence excluded.
- Manifest and checksum verification included; repository tested locally.

## Release authorization and evidence scope
Public distribution requires author/institution authorization and approved reuse terms (see `LICENSE.md`). The final manuscript and letter must be checked against this release before resubmission. Independent project coding, formal venture evidence, permission-cleared interview analysis, finance-ledger reconciliation, and job-level scheduler records are not established by this package; the corresponding limitations remain explicit. The supplied blank templates support subsequent evidence collection but do not assert it was completed.

Create a repository under the authorized GitHub account, initially private if permissions are unresolved. Extract the public package into a clean directory, verify it, commit, run CI, and cite an immutable tag or commit. Do not upload the private archive or reviewer records.
