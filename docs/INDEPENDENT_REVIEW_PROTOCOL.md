# Proposed independent review protocol (not a completed audit)

Freeze a dated deduplicated project register. Assign an assessor unaffiliated with project ownership; record conflicts. Review all higher-stage cases and, preferably, all 50 cases against Table 5. Preserve evidence IDs, dates and decision rationales. Use predeclared use-case-specific thresholds for baseline performance, validation quality, safety, privacy and partner acceptance; do not retrospectively invent thresholds. For iterative AI, allow re-entry to data/model stages, versioned evaluations, drift checks and revalidation. Record contested classifications, second-review decisions and changes to aggregate counts. Report agreement only after actual independent coding. Separate open, paused, re-scoped and discontinued cases at cutoff. The blank templates do not imply that these checks occurred historically.
